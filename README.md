# محاسب (Mohasib)

محاسب هو تطبيق مكتبي عربي أولًا للمحاسبة وإدارة المخزون، مبني باستخدام Electron وReact وTypeScript. يركّز التطبيق على إدارة الحسابات والقيود والفواتير والمخزون والتقارير ضمن بيئة محلية مناسبة للأعمال التي تحتاج إلى نظام محاسبي واضح وسهل الاستخدام.

## المزايا

- لوحة معلومات لمتابعة النشاط المالي.
- دليل الحسابات والقيود اليومية والسندات.
- إدارة العملاء والموردين والجهات ذات العلاقة.
- الفواتير وأوامر البيع والشراء والعروض.
- إدارة الأصناف والمستودعات وحركات المخزون.
- الشيكات والصناديق والبنوك والعملات.
- المصروفات والأصول والرواتب والموظفون.
- الموازنات والأقسام والمشاريع والجهات الممولة.
- تقارير مالية وتشغيلية مع إمكانات الطباعة والتصدير.
- قاعدة بيانات SQLite محلية مع ترحيل محاسبي منظم.

## المتطلبات

- Node.js حديث متوافق مع المشروع.
- npm.
- macOS عند بناء نسخة التوزيع الحالية، والتي تستهدف Apple Silicon (`arm64`).

## التشغيل المحلي

```bash
npm install
npm run dev
```

يفتح الأمر الأخير التطبيق في وضع التطوير.

## الأوامر المتاحة

```bash
npm run typecheck   # فحص TypeScript
npm test            # تشغيل الاختبارات
npm run build       # بناء ملفات التطبيق
npm run build:mac  # بناء حزمة macOS بصيغة DMG لمعمارية arm64
npm run start       # معاينة ناتج البناء
```

## بنية المشروع

- `src/`: واجهة React والصفحات والمكونات والترجمة.
- `electron/`: العملية الرئيسية وواجهات IPC وخدمات قاعدة البيانات والترحيل.
- `shared/`: الأنواع والنماذج المشتركة بين الواجهة وElectron.
- `scripts/`: أدوات الاختبار وتهيئة البيانات التجريبية.
- `out/` و`release/`: نواتج البناء، ولا تُحفظ عادةً في Git.

## ملاحظات مهمة

التطبيق مصمم ليكون عربيًا أولًا، مع وجود دعم للإنجليزية في الواجهة. تُخزّن قاعدة البيانات محليًا على جهاز المستخدم. راجع إعدادات التطبيق وسياسة النسخ الاحتياطي قبل استخدامه في بيانات إنتاجية.

المشروع خاص حاليًا (`UNLICENSED`) وفق إعدادات `package.json`، لذلك لا يُعاد توزيع الكود أو حزم التطبيق دون إذن مالك المشروع.

## الحالة الحالية

هذا المستودع في مرحلة تطوير مستمرة. قبل استخدامه في بيئة إنتاجية، يجب تشغيل الاختبارات، مراجعة إعدادات المحاسبة، وتجربة النسخ الاحتياطي والاستعادة على بيانات تجريبية.
